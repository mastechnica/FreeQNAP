# Personal book import validation — 5 November 2026

The accepted test uses **different books in different formats**, one edition per
title, focused on philosophy, science fiction and dystopia:

| Title | Author | Format | Date | Source |
| --- | --- | --- | --- | --- |
| Meditations | Marcus Aurelius | UTF-8 TXT | Composed circa 170–180 CE | [Project Gutenberg 2680](https://www.gutenberg.org/ebooks/2680) |
| The Time Machine | H. G. Wells | EPUB3 | 1895 | [Project Gutenberg 35](https://www.gutenberg.org/ebooks/35) |
| We | Yevgeny Zamyatin | Kindle AZW3/KF8 | 1924 English edition | [Project Gutenberg 61963](https://www.gutenberg.org/ebooks/61963) |

Project Gutenberg identifies these editions as public domain in the USA. The
original downloaded files retain their included license notices. This is not a
copyright determination for every country or another translation/edition.

Each imported item has a title, author, date, genre, synopsis, digital-edition
publisher, public source link and real cover image from the source EPUB. We's
synopsis identifies Gregory Zilboorg's English translation. Meditations uses a
composition date rather than pretending its modern digital release is the
original publication. No modern ISBN is invented. All three are grouped in a
Philosophy, Sci-Fi & Dystopia collection and appear as readable eBooks, separate
from existing audiobooks.

Acceptance used scoped upload, metadata, artwork and read operations. Each
retained original's bytes matched its downloaded SHA-256. The native readers
returned substantial text and expected content for all three formats; cover
reads returned JPEG images. Extracted text lengths were 424,719, 199,292 and
386,352 characters respectively. This proves these particular readable editions,
not DRM removal or every document variant. No speech or audio was played.

The live family Books page was refreshed and visibly showed thirteen items:
ten existing audiobooks and three distinct eBooks, with the new titles' cover
images and metadata. An account-scoped catalog check found no missing title,
author, genre, synopsis or cover in all thirteen books. Initial lighter-genre
multi-format test editions were withdrawn from the library after the owner's
clarification; only their private staging/evidence was retained. Existing books,
original audio and ongoing photo copies were preserved.
