physical TS-431XeU hardware. Brave supplied administrator views; Firefox supplied
the family account views. These are actual application captures, not invented datasets. The Photos gallery
uses illustrative scenic thumbnails in the explicitly documented image regions. No audio was played and no file operation, Apple
sign-in, storage configuration or notification preference was changed for capture.

- **Overview:** current system pulse, sampled physical indicators, live history,
  healthy internal RAID and actual volume capacity. Offline TR-004 volumes remain

- **iCloud:** active archive progress, gallery counters, retention and map settings.
  The import is still running and attention items remain visible. This screenshot
  does not establish whole-account completeness or resolve its flagged items.
- **Photos gallery:** seven private photo tiles are replaced with generated sunsets

  badges are reproduced within those regions. The surrounding interface, metrics,
  layout and status remain exact original pixels. The showcase labels this exception;
  the scenic images were not added to the NAS. See [scenic asset provenance](../SCENIC-PREVIEW.md).
- **iCloud albums:** a separate close-up of the actual personal-album import
  controls and completed membership pass. Cropping excludes the Apple account,

  respective owners. Their appearance is not endorsement.

Browser tabs, address bars, bookmarks, personal account labels and private paths
are excluded by the crops. Personal photographs, location pins, Apple accounts,
cookies, credentials and device serial numbers are not included. Numeric metrics,
status colors and UI text were not retouched. Original cropped pixels remain
unchanged outside the documented opaque masks and scenic thumbnail regions. PNG exports contain only image
chunks, with no EXIF/GPS/source filename metadata.
