# Family media showcase and source update — 5 November 2026

This update presents the current FreeQNAP source and tested capabilities through
an expanded public showcase, README and live screenshot gallery. The publication
destination is the personal **mastechnica/FreeQNAP** repository and its GitHub Pages
site. Publication uses a clean source snapshot on the existing public history;
private development history, credentials, media originals and device evidence are
excluded.

## Feature coverage

The showcase includes eighteen feature cards, four My Radio media sections and
the installation/hardware/acceptance walkthrough:

| Area | Included capabilities |
| --- | --- |
| Photos and iCloud | Per-user Apple connection, MFA, scheduled archive downloads, visible progress, retained originals, personal album membership and pending-photo attachment |
| Family libraries | Private accounts and storage locations; selected library/album/item sharing; separate read-only Shared with me views |
| Optional Authentik | Dashboard OIDC settings and guide; explicit identity linking; common NAS profile/permissions; separate optional local passwords and reset controls |
| My Radio | Album-based music, metadata/artwork editing, audiobooks/eBooks, series and collections, browser voices/speed/pitch, podcast shows/episodes, US/Canadian radio discovery |
| Metadata and social sharing | Viewer-based XMP location/metadata editing; privacy-copy sharing with original preservation and platform-dependent device share sheet |
| Storage and files | RAID, LUKS2/ext4 password/key unlock, external USB and TR-004, SMB/NFSv4/AFP, Time Machine settings, multi-window file desktop, copy/move, archives, uploads and recycle bin |
| Backup and recovery | Encrypted file/configuration backups, schedules, verification and staged restores; guarded registered-array recovery and rebuild status |
| Network services | Physical ports, addressing/routes, optional private LAN/DHCP/client firewall, OpenVPN/WireGuard client/server/gateway controls and Dynamic DNS |
| Downloads | URL/torrent input, graphical progress, speed/ETA, pause/resume, durable partials and independent retries |
| Media library | Artwork/metadata, explicit provider matching, watched folders, direct playback and DLNA client approval |
| Administration | Token-scoped local agent API, approved renderer controls, account/usage visibility, account-scoped audit history, SMART history/tests, rule-based health notifications and buzzer policy |

The software remains an experimental source project. A fully verified cloud
archive, every hardware failure mode, every client/codec, phone share sheet and
remote-provider setup are not inferred from these screenshots. Five quick taps
and a pitch-controlled shutdown tune remain unaccepted; no new hardware behavior
is enabled for publication. Current acceptance records remain authoritative.
